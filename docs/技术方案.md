## 0. 方案概述

一句话卖点：**上传任何文本，一键生成"情绪曲线驱动"的个性化有声成品——自动匹配音色、语调、语速与背景音乐，并支持克隆/设计任意声音。全部能力由云 API 提供，本地零部署。**

行业背景（2026 年 8 月现状）：中文有声书市场 120 亿+、用户 5.3 亿、年复合增长 25%+；抖音"AI 听书"已将单条内容制作从 2 小时压到 15 分钟。云 TTS 已进入"情感播讲"时代：豆包语音合成模型 2.0（2025-10 发布）实现"理解后的精准情感表达"，5 秒声音复刻相似度 97.5%。现有工具缺三件事：**整篇情绪的动态建模、音色的个性化与自定义、"人味"（重音/停顿/节奏）**——本项目在这三个缺口上做文章。

为什么纯 API：
- 本机无 NVIDIA 独显，本地开源 TTS 实测 RTF≈18.4（1 小时书需 18 小时），不可用于产品化
- 云 API 中文自然度 9.2/10（豆包，实测最高）、情感播讲、5 秒克隆、国内直连 300ms 首包
- Demo 量级成本 ≈ 0~30 元（免费额度覆盖主要路径）
- 产品化 Demo 的稳定性、效果、开发速度全面优于本地推理

核心价值主张：
- 对普通用户：让"有声化"从工具变成创作体验（情绪曲线可视化、音色可设计）
- 对创作者：批量生产+多角色分饰+风格化，替代人工配音流水线
- 对特殊人群（视障/银发/儿童）：语音交互友好的无障碍有声体验

## 1. 目标用户画像与深层需求分析

### 1.1 用户群体总览

| 用户群体 | 表层需求 | 深层需求（痛点本质） | 对应功能落点 |
|---|---|---|---|
| **家长 / 亲子家庭** | 给孩子讲故事音频 | 自己没时间/读不好，但希望保留"陪伴感"与教育性 | 多角色分饰（豆包多音色）、儿童音色、睡前模式（语速放缓+柔和 BGM）、跟读识字模式 |
| **视障人士** | 把任意文字变成可听内容 | TTS"机器味"重、长文无法导航定位、操作门槛高 | 章节/进度语音导航、无界面语音操作、情绪可感知的朗读 |
| **语言学习者**（学中文的老外 / 学外语的国人） | 跟读听力材料 | 需要"可控慢速+清晰重音+双语对照" | 变速朗读、重点词重读标注（SSML 重音）、方言/外语对照（豆包 40+ 语种） |
| **内容创作者**（有声书主播、短视频、播客） | 快速产出配音 | 人工配音贵、周期长、多角色协调难 | 批量合成（长文本异步 10 万字/次）、多角色自动分配、音色库管理、多版本输出 |
| **银发族** | 听书/听新闻 | 普通话听不惯、界面不会用 | 方言朗读（豆包方言音色）、语音交互、一键播放 |
| **通勤 / 助眠人群** | 碎片化听内容 | 情绪与 BGM 不匹配，听感"平" | 情绪曲线驱动 BGM 切换、助眠模式 |

### 1.2 关键洞察（驱动创新的三句话）

1. **情感不是整篇一个标签，而是一条曲线。** 现有 TTS 只支持"这句开心/这句难过"，但真实朗读的感染力来自**情绪的起伏、转折和铺垫**——这正是情绪曲线建模的价值。
2. **音色是最大的个性化入口。** "用自己的声音给孩子讲故事""用四川话给外婆读书"——声音的个性化比音质更打动人。
3. **"人味"=重音+停顿+语气词的节奏。** 用户能感知 AI 与真人的差距，主要不在音色，在**该重读的地方没重读、该停顿的地方没停顿**。

### 1.3 由此拓展的新应用场景

- **家庭记忆有声化**：家书、日记、老照片配文用本人克隆音色朗读，制成永久音频纪念品
- **教案/课件有声化**：教师上传课件，自动生成可听版+重点强调
- **小说章节试听+多角色广播剧**：短篇一键生成广播剧效果（Demo 主打场景）
- **无障碍政务/社区信息播报**：方言播报通知，服务银发与视障群体
- **AI 主播频道**：创作者用设计音色（非真人克隆，规避版权）批量做口播号

## 2. 创新功能点（市场价值 × 技术可行性）

### F1. 情绪曲线编辑器（核心差异化，Demo 杀手锏）
- **功能**：LLM 对全篇文本生成细粒度情绪标注（标签+强度 0~1+建议语速/停顿），渲染为**可拖拽编辑的情绪曲线**；用户拖动某一段的情绪值，系统只重合成该段语音，其余不动。
- **市场价值**：把"AI 生成"升级为"人机共创"，解决 AI 情感误判的信任问题；市面上没有同类交互形态。
- **技术可行**：分段缓存 + 段落级增量合成（豆包分段/异步长文本接口，单段秒级返回）。

### F2. 智能多角色分饰
- **功能**：LLM 自动识别对话/旁白，抽取说话人，为每角色分配预置音色或复刻音色，生成广播剧效果。
- **市场价值**：儿童故事、小说、广播剧创作者刚需；人工多角色配音成本极高。
- **技术可行**：豆包 200+ 预置音色 + 多角色参数同请求切换；声音复刻 2.0 每角色 5 秒样本。

### F3. "人味"重音与停顿注入
- **功能**：LLM 标注重音词/停顿点，映射为豆包 SSML 重音标记 + 指令式情感控制（如 `[急切而发颤]` 细节描述）。
- **市场价值**：直击"AI 朗读味"痛点，是听感提升性价比最高的一环。
- **技术可行**：豆包完整 SSML + 自然语言情感指令，98% 断句/重音准确率。

### F4. 音色三合一：克隆 / 设计 / 方言
- **功能**：**克隆**——豆包声音复刻 2.0（5 秒音频，相似度 97.5%，免费 15 次训练）；**设计**——MiniMax Voice Design（自然语言描述生成全新音色，$3/个）；**方言**——豆包 40+ 语种/方言音色（四川话/粤语等）。
- **市场价值**：覆盖"模拟输入音色 + 自定义音色"进阶诉求；方言直接服务银发族与地域内容市场。
- **技术可行**：云 API 原生能力，无本地推理。

### F5. 情绪驱动的背景音乐智能匹配
- **功能**：段落情感标签 → 情绪化 CC0 曲库检索（欢快/悲伤/紧张/平静/激昂）+ 云内 ffmpeg ducking（语音时音乐压低）+ 情绪转折平滑切换。
- **市场价值**：BGM 是成品感的最大加分项；"文本→BGM 自动匹配"没有成熟开源产品。
- **技术可行**：情绪标签化 CC0 曲库（COS 存储）+ 云内 ffmpeg 侧链压缩；可选 Suno API 生成（免版权）。

### F6. 一键多版本输出
- **功能**：同一文本一键产出 正常版/慢速助眠版/双语对照版/30 秒预告片。
- **市场价值**：创作者分发刚需；Demo 展示"一键生成多种成品"视觉冲击力强。
- **技术可行**：同管线改参数重跑，低增量成本。

## 4. 技术选型（纯 API，2026-08 价格）

| 环节 | 选型 | 关键能力 | 价格 |
|---|---|---|---|
| **情感/文本分析** | **GLM-4-Flash**（智谱，完全免费）为主；DeepSeek/Kimi 备 | 结构化 JSON、长上下文、中文理解强 | 免费（备选 ~0.5 元/百万 token） |
| **TTS 主引擎** | **火山引擎豆包语音合成模型 2.0** | 情感播讲（自然语言控情绪）、200+ 预置音色、多角色、SSML、流式 300ms、长文本异步 10 万字/次、40+ 语种方言 | 后付费 3 元/万字符；新用户免费额度（合成约 2 万~50 万字符级） |
| **音色克隆** | **豆包声音复刻 2.0** | 5 秒克隆、相似度 97.5%、支持小说配音场景 | 免费 15 次训练；音色槽位 138 元/音色（Demo 用免费额度） |
| **自定义音色设计** | **MiniMax Voice Design（Speech 2.8 家族）**；可选通道：**阿里云百炼 CosyVoice**（配置 `DASHSCOPE_API_KEY` 即启用，未配置自动回落 MiniMax） | 自然语言描述生成新音色（voice_id + 试听）；emotion 参数 9 种 + sound tags + pitch/intensity/timbre 调节。CosyVoice 通道：纯 HTTP REST（设计 `voice-enrollment/create_voice` + 合成 `SpeechSynthesizer`），创建**免费**、合成 ¥1.5/万字符 | MiniMax：$3/音色（≈21.6 元，一次性）；TTS $60/百万字符 ≈ **4.32 元/万字符**（旧记「0.4 元/万字」系换算错误 10 倍，2026-09-01 更正）。CosyVoice：设计 0 元。两通道共用 `voice_design_cache` 按描述哈希缓存（含 provider 字段），同描述同通道不重复计费 |
| **BGM** | 情绪化 CC0 曲库（存 COS）；可选 Suno API 生成 | 情绪维度标签：欢快/悲伤/紧张/平静/激昂 | CC0 免费；Suno 按量 |
| **后期混音** | **CloudBase 云托管容器内 ffmpeg**（或云函数 ffmpeg 层） | loudnorm / sidechaincompress / concat | 随云资源计费，量极小 |
| **后端** | **CloudBase 云函数 + 云数据库 + COS** | 任务队列（asyncio）、分段缓存、静态托管一体 | Demo 量级约几元/月 |
| **前端** | 单页 HTML/JS（情绪曲线用可拖拽 SVG/Canvas） | 静态托管 CloudBase Hosting | 免费额度内 |

**成本估算（Demo 全程）**：LLM 0 元（GLM-4-Flash 免费）+ TTS 免费额度内 + 复刻免费 15 次 + Voice Design ~21 元（1 个）+ 云资源几元 ≈ **总成本 0~30 元**。

**关键链路（一次合成数据流）**：

```
文本 → GLM-4-Flash: 分段+情感曲线+角色+重音 (JSON)
     → 情绪曲线可视化（前端可编辑，改段只重算该段）
     → 豆包 TTS: 每段按情感/角色参数合成（角色音色: 复刻音色）
     → 云内 ffmpeg: 拼接 + BGM 按段情感匹配 + ducking + 响度归一化
     → 成品存 COS + 播放器预览 + 多版本导出
```

## 5. 实施阶段规划（分阶段里程碑）

### M0 · 技术验证（第 1~2 周）——验证点：四链路全部跑通
- [ ] 开通火山引擎账号 + 豆包语音服务，申请 AppID/Token；确认免费额度
- [ ] 豆包 TTS 跑通：自然语言情感指令（同句两种情绪听感差异）+ SSML 重音/停顿
- [ ] 声音复刻 2.0：上传 5~10 秒参考音频 → 复刻音色 → 用该音色合成
- [ ] MiniMax Voice Design：文本描述生成新音色 → 用该音色合成（自定义音色验证）
- [ ] GLM-4-Flash 情感分析 JSON 模板调通（分段/情感/强度/角色/重音词）
- **里程碑验收**：一段 300 字故事，两种情绪指令 + 克隆音色 + 设计音色各出一版，听感差异明显

### M1 · MVP 流水线（第 3~5 周）——验证点：脚本/云函数可一键出成品
- [ ] CloudBase 环境搭建（云函数 + 云数据库 + COS + 静态托管）
- [ ] 文本分析云函数（LLM 分段+情感+角色+重音）
- [ ] 合成编排云函数（情感参数→豆包 API 参数，分段调用、增量重合成）
- [ ] 后期云函数（云内 ffmpeg 拼接+响度+BGM 匹配+ducking）→ 成品存 COS
- [ ] CLI/测试脚本：`python pipeline.py story.txt --voice 复刻音色 --bgm auto` 调云端 API → 输出成品
- **里程碑验收**：短篇故事（~1000 字）一键产出带 BGM 完整音频，无拼接破绽

### M2 · 产品化 Demo 前端（第 6~8 周）——验证点：完整交互闭环
- [ ] 前端静态页：文本上传 → 情绪曲线编辑器（拖拽改情感，段落级局部重合成）→ 音色面板（预置/复刻/设计）→ BGM 选择 → 成品播放/导出
- [ ] 音色与素材管理：复刻音色记录、设计音色、情绪化 BGM 库（云数据库）
- [ ] 队列与缓存：长任务异步化、同文本缓存、额度监控
- **里程碑验收**："科幻短篇→多角色广播剧"完整 Demo 流程，曲线拖拽后段落级重合成秒级返回

### M3 · 打磨与展示（第 9~10 周）——验证点：演示稳定、效果惊艳
- [ ] 多角色分饰正式化（角色抽取→自动分配音色→成品）
- [ ] 方言通道（豆包方言音色，银发族场景演示）
- [ ] 一键多版本输出（正常/慢速/双语/预告片）
- [ ] 预生成演示素材（存 COS 离线兜底，防现场 API 抖动）+ 演示脚本 + 录屏
- **里程碑验收**：10 分钟演示稳定跑完，3 类场景（亲子故事/广播剧/方言播报）各有成品

## 6. 预期难点与风险及应对策略

| # | 风险/难点 | 影响 | 应对策略 |
|---|---|---|---|
| R1 | **情感分析误判**（讽刺/双关/语境反转） | 语调错配，听感违和 | ① LLM prompt 加"全局上下文窗口"（参考前文情绪趋势）；② 情绪曲线编辑器人工拖拽修正（把误判变可控流程）；③ 低置信度段落回退中性 |
| R2 | **API 限流/并发**（免费额度、QPS 上限） | Demo 卡顿 | ① 云函数并发配置 + 任务队列；② 结果缓存（同文本不重调）；③ 免费额度监控 + 预警 |
| R3 | **费用失控** | 成本超预算 | ① 字数统计 + 额度预警（云函数内计数）；② 段落级缓存避免重复计费；③ Demo 素材预生成，现场只走缓存回放 |
| R4 | **厂商依赖**（接口变更/价格调整/服务故障） | 功能不可用 | ① TTS 适配层抽象（火山豆包主 / MiniMax 备，一键切换）；② LLM 多厂商可切换；③ 关键故障降级提示 |

## 7. 合规与伦理边界（产品化必须提前定）

- **音色克隆**：只接受本人声音或提供授权证明的声音；界面显著提示"请确保拥有声音权利"
- **内容安全**：合成文本前置过滤（LLM 安全审查 + 敏感词表）
- **数据隐私**：文本仅用于本次合成、不留存；Demo 数据不涉敏感
- **AI 标识**：成品音频加 AI 生成说明（符合深度合成管理规定）
- **云平台条款**：遵守火山引擎/MiniMax/CloudBase 服务条款与内容规范
