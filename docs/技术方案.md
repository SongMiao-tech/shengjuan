## 0. 方案概述

一句话卖点：**上传任何文本，一键生成"情绪曲线驱动"的个性化有声成品——自动匹配音色、语调、语速与背景音乐，并支持克隆/设计任意声音。全部能力由云 API 提供，本地零部署。**

**落地状态（2026-09-02）**：本方案已全部落地并上线——双页产品（工作台 + 睡前故事播放器）、账号体系、音色库、跨页书架、家长中心均可用，端到端浏览器 E2E 全绿。产品定位已收敛为「有声读物工作台 + 睡前故事播放器」双核心、聚焦亲子家庭（详见 PRD v2.0），里程碑明细见 PROJECT_CHARTER §4。

行业背景（2026 年 8 月现状）：中文有声书市场 120 亿+、用户 5.3 亿、年复合增长 25%+；抖音"AI 听书"已将单条内容制作从 2 小时压到 15 分钟。云 TTS 已进入"情感播讲"时代：豆包语音合成模型 2.0（2025-10 发布）实现"理解后的精准情感表达"，5 秒声音复刻相似度 97.5%。现有工具缺三件事：**整篇情绪的动态建模、音色的个性化与自定义、"人味"（重音/停顿/节奏）**——本项目在这三个缺口上做文章。

为什么纯 API：
- 本机无 NVIDIA 独显，本地开源 TTS 实测 RTF≈18.4（1 小时书需 18 小时），不可用于产品化
- 云 API 中文自然度 9.2/10（豆包，实测最高）、情感播讲、5 秒克隆、国内直连 300ms 首包
- Demo 量级成本 ≈ 0~30 元（免费额度覆盖主要路径）
- 产品化 Demo 的稳定性、效果、开发速度全面优于本地推理

核心价值主张：
- 对普通用户：让"有声化"从工具变成创作体验（情绪曲线可视化、音色可设计）
- 对创作者：批量生产+多角色分饰+风格化，替代人工配音流水线
- 对特殊人群（视障/银发/儿童）：语音交互友好的无障碍有声体验

## 1. 目标用户画像与深层需求分析

### 1.1 用户画像（2026-08-31 收窄，对齐 PRD v2.0）

聚焦**亲子家庭**一类人群——睡前场景对「情绪动态建模、多角色分饰、家长音色复刻」的需求密度最高，是差异化能力的最佳落点：

| 使用角色 | 典型场景 | 核心诉求 | 对应功能落点 |
|---|---|---|---|
| **家长**（生产 + 管控） | 白天制作、睡前设置 | 用现成公版书/读本快速做成有情绪、多角色的有声书；克隆或设计「妈妈声/爸爸声」，用方言祖辈音色讲老家故事；查看收听报告，设置每日上限与就寝时段 | 情绪曲线编辑器、多角色分饰、音色三合一（克隆/设计/方言）、跨页书架、家长中心 |
| **孩子**（消费） | 睡前收听 | 打开就能听经典故事；听爸爸妈妈做的专属故事；界面大按钮、夜间友好；断点续听、断网也能听 | 20 篇公版故事库、儿童播放器、迷你播放栏、离线缓存 |

> 原 v1.0 规划中的内容创作者、视障/银发、语言学习者、通勤助眠四类人群不再单独展开——其能力诉求（变速/方言/批量/无障碍）与亲子场景高度重叠，产品能力天然覆盖，未来如有需要可作潜在拓展市场回归。

### 1.2 关键洞察（驱动创新的三句话）

1. **情感不是整篇一个标签，而是一条曲线。** 现有 TTS 只支持"这句开心/这句难过"，但真实朗读的感染力来自**情绪的起伏、转折和铺垫**——这正是情绪曲线建模的价值。
2. **音色是最大的个性化入口。** "用自己的声音给孩子讲故事""用四川话给外婆读书"——声音的个性化比音质更打动人。
3. **"人味"=重音+停顿+语气词的节奏。** 用户能感知 AI 与真人的差距，主要不在音色，在**该重读的地方没重读、该停顿的地方没停顿**。

### 1.3 由此拓展的新应用场景

- **家庭记忆有声化**：家书、日记、老照片配文用本人克隆音色朗读，制成永久音频纪念品
- **教案/课件有声化**：教师上传课件，自动生成可听版+重点强调
- **小说章节试听+多角色广播剧**：短篇一键生成广播剧效果（工作台能力线的演示亮点）
- **无障碍政务/社区信息播报**：方言播报通知，服务银发与视障群体
- **AI 主播频道**：创作者用设计音色（非真人克隆，规避版权）批量做口播号

## 2. 创新功能点（市场价值 × 技术可行性）

### F1. 情绪曲线编辑器（核心差异化，Demo 杀手锏）✅ 已上线
- **功能**：LLM 对全篇文本生成细粒度情绪标注（标签+强度 0~1+建议语速/停顿），渲染为**可拖拽编辑的情绪曲线**；用户拖动某一段的情绪值，系统只重合成该段语音，其余不动。
- **市场价值**：把"AI 生成"升级为"人机共创"，解决 AI 情感误判的信任问题；市面上没有同类交互形态。
- **技术可行**：分段缓存 + 段落级增量合成（豆包分段/异步长文本接口，单段秒级返回）。

### F2. 智能多角色分饰 ✅ 已上线
- **功能**：LLM 自动识别对话/旁白，抽取说话人，为每角色分配预置音色或复刻音色，生成广播剧效果。
- **市场价值**：儿童故事、小说、广播剧创作者刚需；人工多角色配音成本极高。
- **技术可行**：豆包 200+ 预置音色 + 多角色参数同请求切换；声音复刻 2.0 每角色 5 秒样本。

### F3. "人味"重音与停顿注入 ✅ 已上线
- **功能**：LLM 标注重音词/停顿点，映射为豆包 SSML 重音标记 + 指令式情感控制（如 `[急切而发颤]` 细节描述）。
- **市场价值**：直击"AI 朗读味"痛点，是听感提升性价比最高的一环。
- **技术可行**：豆包完整 SSML + 自然语言情感指令，98% 断句/重音准确率。

### F4. 音色三合一：克隆 / 设计 / 方言（+ 音色库 / 智能生成）✅ 已上线
- **功能**：**克隆**——豆包声音复刻 2.0（5 秒音频，相似度 97.5%，免费 15 次训练）；**设计**——阿里云百炼 CosyVoice 声音设计（免费）为主通道 / MiniMax Voice Design 备用（$3/个）；**方言**——豆包 40+ 语种/方言音色（四川话/粤语等）。
- **音色库与多设备同步**（2026-09-01 上线）：PG 表 `user_voice_library`（PK=(uid,voice_id)，上限 20 条，RLS 隔离），接口 `GET/POST /me/voices`、`PATCH/DELETE /me/voices/<voice_id>`；名称非空、≤16 字、仅中英文/数字/空格/·-_、全局唯一（trim+忽略大小写），同名同 voice_id 视为覆盖更新。登录用户云端全量同步（localStorage 仅断网缓存），未登录走本地库、登录后自动迁移上云。
- **智能生成音色**（2026-09-01 上线）：用户一句话描述（1~300 字）→ GLM「配音导演」prompt 扩写为专业 voice_prompt（60~200 字，覆盖性别年龄/音质/语速/情感基调/适用题材）+ 命名建议（4~8 字）→ 复用 `_design_core`（缓存/免费 CosyVoice 设计）→ 回显 AI 设定 + 试听 + 预填建议名保存。GLM 失败有模板兜底；输出引号统一剥离防 JSON 未转义污染；设计成功但试听合成失败时降级返回 voice_id（preview_base64=None + note），不丢音色。
- **市场价值**：覆盖"模拟输入音色 + 自定义音色"进阶诉求；方言直接服务银发族与地域内容市场；智能生成把"描述音色"门槛降到一句话。
- **技术可行**：云 API 原生能力，无本地推理。

### F5. 情绪驱动的背景音乐智能匹配 ✅ 已上线
- **功能**：段落情感标签 → 情绪化 CC0 曲库检索（欢快/悲伤/紧张/平静/激昂）+ 云内 ffmpeg ducking（语音时音乐压低）+ 情绪转折平滑切换。
- **市场价值**：BGM 是成品感的最大加分项；"文本→BGM 自动匹配"没有成熟开源产品。
- **技术可行**：情绪标签化 CC0 曲库（容器内置 assets/bgm）+ 云内 ffmpeg 侧链压缩；可选 Suno API 生成（免版权）。

### F6. 一键多版本输出 ✅ 已上线
- **功能**：同一文本一键产出 正常版/慢速助眠版/双语对照版/30 秒预告片。
- **市场价值**：创作者分发刚需；Demo 展示"一键生成多种成品"视觉冲击力强。
- **技术可行**：同管线改参数重跑，低增量成本。

### F7. 跨页书架与移动端体验 ✅ 已上线（2026-09-01）
- **功能**：工作台成品一键存书架（PG `user_audiobooks`，音频 base64），睡前故事页同步可听、进度跨页跨设备一致；书架条目**一键下载 MP3**——纯前端 fetch 流式读取（端点不鉴权、16 位随机 id 难枚举），按 Content-Length 显示下载百分比，状态机 ⤓ → xx% → ✓（2s 回弹），文件名取书名并 sanitize，两页（工作台/睡前故事）复用同一份 `downloadBook` 逻辑。
- **移动端适配**：≤900px 堆叠布局下书架视图隐藏音色侧栏直达内容（body.v-shelf 开关）；≤640px 区块头部两行化、书架操作键 34→40px 触控目标；迷你播放栏高度含 `env(safe-area-inset-bottom)`，内容居中在全面屏手势条之上（Android 15 边缘到边缘内嵌浏览器截断问题的修复）。
- **市场价值**：下载满足离线/外放/转存诉求；移动端体验决定家长实际使用率（哄睡场景大概率发生在手机上）。
- **技术可行**：后端零改动，纯前端实现；E2E 16/16（playwright 捕获 download 事件验证文件落盘与状态流转）。

## 4. 技术选型（纯 API，2026-08 价格）

| 环节 | 选型 | 关键能力 | 价格 |
|---|---|---|---|
| **情感/文本分析** | **GLM-4-Flash**（智谱，完全免费）为主；DeepSeek/Kimi 备 | 结构化 JSON、长上下文、中文理解强 | 免费（备选 ~0.5 元/百万 token） |
| **TTS 主引擎** | **火山引擎豆包语音合成模型 2.0** | 情感播讲（自然语言控情绪）、200+ 预置音色、多角色、SSML、流式 300ms、长文本异步 10 万字/次、40+ 语种方言 | 后付费 3 元/万字符；新用户免费额度（合成约 2 万~50 万字符级） |
| **音色克隆** | **豆包声音复刻 2.0** | 5 秒克隆、相似度 97.5%、支持小说配音场景 | 免费 15 次训练；音色槽位 138 元/音色（Demo 用免费额度） |
| **自定义音色设计** | **MiniMax Voice Design（Speech 2.8 家族）**；可选通道：**阿里云百炼 CosyVoice**（配置 `DASHSCOPE_API_KEY` 即启用，未配置自动回落 MiniMax） | 自然语言描述生成新音色（voice_id + 试听）；emotion 参数 9 种 + sound tags + pitch/intensity/timbre 调节。CosyVoice 通道：纯 HTTP REST（设计 `voice-enrollment/create_voice` + 合成 `SpeechSynthesizer`），创建**免费**、合成 ¥1.5/万字符 | MiniMax：$3/音色（≈21.6 元，一次性）；TTS $60/百万字符 ≈ **4.32 元/万字符**（旧记「0.4 元/万字」系换算错误 10 倍，2026-09-01 更正）。CosyVoice：设计 0 元。两通道共用 `voice_design_cache` 按描述哈希缓存（含 provider 字段），同描述同通道不重复计费 |
| **BGM** | 情绪化 CC0 曲库（**容器内置 `assets/bgm`**，前端程序化合成备用）；可选 Suno API 生成 | 情绪维度标签：欢快/悲伤/紧张/平静/激昂 | CC0 免费；Suno 按量 |
| **后期混音** | **CloudBase 云托管容器内 ffmpeg** | loudnorm / sidechaincompress / concat | 随云资源计费，量极小 |
| **后端** | **CloudBase 云托管容器（Flask）+ PG 数据库**（REST，service_role 绕 RLS） | 任务队列（asyncio）、分段缓存、账号/书架/音色库/家长中心、用量监控 | MinNum=0 省点模式，Demo 量级约几元/月 |
| **前端** | 双页单 HTML/JS（情绪曲线用可拖拽 SVG/Canvas），无构建 | 静态托管 CloudBase Hosting；共享 localStorage，手机端适配 | 免费额度内 |

**成本估算（Demo 全程）**：LLM 0 元（GLM-4-Flash 免费）+ TTS 免费额度内 + 复刻免费 15 次 + Voice Design ~21 元（1 个）+ 云资源几元 ≈ **总成本 0~30 元**。

**关键链路（一次合成数据流）**：

```
文本 → GLM-4-Flash: 分段+情感曲线+角色+重音 (JSON)
     → 情绪曲线可视化（前端可编辑，改段只重算该段）
     → 豆包 TTS: 每段按情感/角色参数合成（角色音色: 复刻音色）
     → 云内 ffmpeg: 拼接 + BGM 按段情感匹配 + ducking + 响度归一化
     → 成品存 PG（base64，书架可下载/跨页播放） + 播放器预览 + 多版本导出
```

## 6. 预期难点与风险及应对策略

> 落地注记（2026-09-02）：R1~R4 的核心应对已实装——情绪曲线人工修正、同文本缓存与设计缓存、额度监控、TTS 适配层多通道切换、演示素材离线兜底；R5~R7 的合规机制见 §7。

| # | 风险/难点 | 影响 | 应对策略 |
|---|---|---|---|
| R1 | **情感分析误判**（讽刺/双关/语境反转） | 语调错配，听感违和 | ① LLM prompt 加"全局上下文窗口"（参考前文情绪趋势）；② 情绪曲线编辑器人工拖拽修正（把误判变可控流程）；③ 低置信度段落回退中性 |
| R2 | **API 限流/并发**（免费额度、QPS 上限） | Demo 卡顿 | ① 云托管容器 + 任务队列（asyncio）；② 结果缓存（同文本不重调）；③ 免费额度监控 + 预警 |
| R3 | **费用失控** | 成本超预算 | ① 字数统计 + 额度预警（服务端计数）；② 段落级缓存避免重复计费；③ Demo 素材预生成，现场只走缓存回放 |
| R4 | **厂商依赖**（接口变更/价格调整/服务故障） | 功能不可用 | ① TTS 适配层抽象（火山豆包主 / MiniMax 备，一键切换）；② LLM 多厂商可切换；③ 关键故障降级提示 |
| R5 | **内容合规**（云厂商内容审核） | 请求被拒/封禁 | ① 前置内容安全过滤（GLM 安全审查 + 敏感词表）；② 演示素材合规自检 |
| R6 | **数据隐私**（文本上传第三方） | 用户信任问题 | ① 隐私声明（文本仅用于本次合成）；② Demo 数据不涉敏感；③ "不留存"承诺 |
| R7 | **音色克隆伦理** | 侵权风险、平台封禁 | ① 仅克隆本人/已授权声音，界面显著提示；② 符合厂商平台合规要求；③ 演示只用预置音色+自录声音 |
| R8 | **Demo 现场翻车**（网络/API 抖动） | 展示事故 | ① 全部演示素材预生成离线备份；② 现场优先缓存回放；③ 断网降级提示 |

## 7. 合规与伦理边界（产品化必须提前定）

- **音色克隆**：只接受本人声音或提供授权证明的声音；界面显著提示"请确保拥有声音权利"
- **内容安全**：合成文本前置过滤（LLM 安全审查 + 敏感词表）
- **数据隐私**：文本仅用于本次合成、不留存；Demo 数据不涉敏感
- **AI 标识**：成品音频加 AI 生成说明（符合深度合成管理规定）
- **云平台条款**：遵守火山引擎/MiniMax/CloudBase 服务条款与内容规范

## 8. 演示脚本建议（产品化 Demo 加分项）

主场景：**"亲子睡前故事：白天制作 → 晚上哄睡"**（对齐双核心定位：工作台是厨房，睡前故事是餐桌）

1. 开场（白天 · 家长视角）：在工作台从公版故事库选一篇经典童话 → 自动生成情绪曲线（视觉冲击点：整篇情绪起伏一目了然）
2. 定制声音：现场演示"用一句话生成一个新声音"（如：温柔的妈妈声），或用 5 秒录音克隆本人音色——"用自己的声音给孩子讲故事"
3. 拖拽：把高潮段情绪调柔/调急 → 段落级重合成秒级返回 → 播放前后对比（核心差异化）
4. 成品：一键多版本（正常 / 慢速助眠版）+ BGM 自动匹配 → 存入书架
5. 收听（晚上 · 孩子视角）：切到睡前故事页，打开书架点播，进度跨页跨设备一致；迷你播放栏 + 断点续听 + 家长中心收听报告收尾
6. 彩蛋：手机端打开（375px 视口）展示移动端适配与一键下载 MP3

备选场景（工作台能力线，展示技术广度）：科幻短篇 → 多角色广播剧（复刻音色分饰角色）；银发方言播报（四川话读通知，切方言通道）

> 演示兜底：关键素材预生成离线备份，现场优先走缓存回放，防 API 抖动。
