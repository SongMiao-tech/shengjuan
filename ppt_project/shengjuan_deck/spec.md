# spec · 声卷演示文稿

## 1. 主题
**声卷** —— 把一段文字，变成一本能听、有情绪、有角色声音的有声书
场景：课程演示 / 答辩现场（5 分钟汇报配套幻灯片）

## 2. 页数
**8 页**，1:1 对应 `docs/演示逐字稿.md` 的 P1–P8，翻页节奏与演讲一致
（不单独做封面页与致谢页：P1 即开场页，P8 即收尾页）

## 3. 风格
**Swiss Grid（瑞士网格）**
- 背景 `#FFFFFF` / 主色 `#000000` / 强调 `#E63946`（每页仅一处）/ 次级块 `#F1F1F1`
- 12 列网格，模块间距 24px；标题左对齐 44–64px；正文 18–22px；标签全大写 12px、字间距 0.1em
- 禁忌：无渐变、无阴影、无圆角、无装饰图形（功能性几何如折线/条形为数据表达，允许）

## 4. 画布
1280 × 720（16:9 标准 PPT）

## 5. 字体（PowerPoint 安全字体，勿用 Inter / Helvetica Neue）
- 中文：`微软雅黑`（标题 Bold / 正文 Regular）
- 英文与数字：`Arial`
- 行高 1.2；字重对比 Bold + Regular，不用斜体

## 6. 素材
- 源：`docs/演示逐字稿.md`（唯一内容来源，不额外虚构）
- 图片：**无**。全部用文字 + 功能性几何（折线、条形、流程箭头、栅格块）表达
- 需保留的硬数据：RTF 18.4 / 一小时等十八小时 / MiniMax 一个音色二十多块 / CosyVoice 创建免费 / 4.32 元每万字符 / 十六条 Playwright 断言 / 三轮迭代

## 7. 去 AI 味硬约束
- 每页一个核心信息点，标题 ≤ 20 字，要点 ≤ 30 字/条
- 不用「首先/其次/最后」「综上所述」「赋能/全方位/一站式」
- 不强行凑三点：两点即两点
- 保留演讲原话中的口语措辞（「没有人味」「不是账号，是参数」「四毛钱一万字」「当草稿，不当答案」）
- 数据 > 形容词
