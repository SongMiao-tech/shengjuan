声卷·整体架构
三层九模块：前端入口 → Flask 中枢调度 → 三大底座协同生成有声书
L1 · 入口层
前端（CloudBase 静态托管 · 双页单 HTML · 无构建）
  • 工作台 index.html　创作 + 书架
  • 睡前故事 story.html　收听 + 跨页书架 + 迷你播放栏
  • 共享 localStorage　sqAuth / 断网音色缓存
HTTP(S) + Bearer token
L2 · 中枢层
后端 audiobook-api（CloudBase 云托管容器 · Flask）
  • /auth/*　账号（自建 PBKDF2 + HMAC token）
  • /tasks　生成编排（情感分析 → 分段 → 合成）
  • /voices/*　音色三合一（设计 / 克隆 / 方言）
  • /me/voices　音色库　·　/me/audiobooks　书架
  • 任务队列 asyncio　·　分段缓存
  • 用量监控　·　分析缓存
  • 云内 ffmpeg 后期（BGM 混音 / 段落拼接）
  • 家长中心　·　收听上报
L3-A · 数据
CloudBase PG六张表
  • users　账号 / token
  • user_voice_library　我的音色
  • user_audiobooks　生成结果 + 收听日志
  • voice_design_cache　跨用户设计缓存
L3-B · 智能
外部云 API按需选型
  • 情感分析　GLM-4-Flash（免费）
  • TTS　豆包 2.0 + 复刻 2.0
  • 音色设计　CosyVoice（主/免费）
    + MiniMax（备）
L3-C · 素材
容器内置素材本地缓存
  • assets/bgm　情绪化 CC0 曲库
情绪标签　 欢快悲伤紧张平静激昂
一句话：浏览器 → Flask → 三大底座（数据 / 智能 / 素材），所有合成与设计按段异步、可监控、可降级。
